# Next.js 16.4.1 → 16.4.6 보안 업그레이드

2026-11-17

## 왜

`next dev` 가 실행 중 멈추면서 현재 설치된 16.4.1 이 공개된 보안 권고에 걸려 있다고 알렸다.
첫 실행은 안내만 띄우고 종료했고, 같은 명령을 한 번 더 돌려야 서버가 떴다.

참고: <https://registry.npmjs.org/-/npm/v1/security/advisories/bulk>

## 무엇을 했나

`next upgrade --agent=security` 를 돌렸다. 이 명령이 직접 패키지를 바꾸지는 않는다.
대상 버전(16.4.6)과 따라야 할 체크리스트를 내놓고 끝난다.

### 사전 확인 — 중복 작업 없음

- 열린 PR 없음 (`gh pr list --state open` → `[]`)
- `origin/next16-upgrade` 는 main 보다 0 커밋 앞서 있다. 이미 머지된 옛 15 → 16 작업이고
  거기 `package.json` 은 아직 16.1.6 이다
- 워킹트리 깨끗

별도 worktree 를 만들지 않고 현재 체크아웃에서 진행했다. 패치 버전 올림이고 트리가
깨끗해서, worktree 를 쓰면 `pnpm install` 을 한 벌 더 돌린 뒤 결국 여기서 다시
설치해야 한다.

### 변경

| 파일 | 내용 |
|---|---|
| `package.json` | `next` 16.4.1 → 16.4.6 |
| `pnpm-lock.yaml` | 잠금 파일 갱신 (+3 −3 패키지) |
| `next.config.ts` | `experimental.agentUpgrade: "security"` 추가 |

`agentUpgrade` 는 `next dev` 가 띄우는 업그레이드 안내의 범위를 정한다. `"security"` 는
보안 권고가 나온 버전만 알리게 한다. 끄는 설정이 아니다.
타입은 `node_modules/next/dist/server/config-shared.d.ts:367` 에 있다 —
`'security' | 'latest' | 'experimental-future' | false`.

메이저가 바뀌지 않았으므로 codemod 는 돌리지 않았다.

## 검증

| 항목 | 결과 |
|---|---|
| `next --version` | `Next.js v16.4.6` |
| `tsc --noEmit` | 통과 |
| `pnpm test` | 147/147 통과 |
| `pnpm build` | exit 0 |
| 정적 출력 | `out/` 에 html 94개, sitemap `<loc>` 92개 |
| `pnpm dev` | `/`, `/scion-source-control`, `/en/scion-source-control` 모두 200 |
| 보안 경고 | 사라짐 |

출력 페이지 수는 본문과 맞는다. 글이 한국어 24편 · 영문 24편이고 `draft: true` 인 글은
없다.

## 남은 것

업그레이드 도구가 마지막에 텔레메트리 한 줄
(`npx next@16.5.0-canary.53 internal report-agent-upgrade <uuid> success`)을 요청했는데,
외부 통신이라 이 환경에서 차단됐다. 프로젝트 정보는 담기지 않는 UUID 한 개짜리 신호라
업그레이드 자체와는 무관하다. 보내지 않았다.

`pnpm lint` 는 여전히 깨져 있다 (Next 16 에서 `next lint` 제거). 이번 작업 범위 밖이라
건드리지 않았다. 린트는 `npx eslint <경로>` 로 돌린다.
